# DeepSeek Harness TUI 使用说明

> 本说明对应本仓库的一键安装器（TUI 版）。分两部分：**一、安装过程**（安装器做了什么、窗口怎么填）；**二、TUI 指令与操作**（斜杠指令 `/btw` 等、快捷键、鼠标、环境变量）。
> 内容依据 dsh-TUI v0.9.x 官方文档整理（[交互与命令](https://github.com/ccch1mneyyy/dsh-TUI/blob/main/docs/interaction.md)、[配置参考](https://github.com/ccch1mneyyy/dsh-TUI/blob/main/docs/configuration.md)、[快速开始](https://github.com/ccch1mneyyy/dsh-TUI/blob/main/docs/getting-started.md)）。

## 一、安装过程

### 1.1 前置条件

安装器会**自动处理**以下环境，你只需要满足：Windows 10/11、能联网。

| 组件 | 要求 | 安装器行为 |
|---|---|---|
| Node.js | `^22.19 || >=24` | 缺失/过旧时自动安装最新 LTS **便携版**（免管理员，不动现有 Node） |
| `@deepseek-ai/dsh` | 官方 Harness CLI | `npm install -g` 自动安装 |
| `@deepseek-harness-tui/dsh-tui` | TUI 前端（默认稳定版 0.9.3，可选 latest 尝鲜） | 同上 |
| pnpm | `>=10` | 缺失时 `npm install -g pnpm@latest` |
| DeepSeek API Key | `sk-` 开头 | 在安装窗口里填写 |

### 1.2 一键安装（install.bat）

1. 下载本仓库并解压，双击 **`install.bat`**（无需管理员权限，双击即用，已内置 `-ExecutionPolicy Bypass`）。
2. 在弹出的配置窗口中填写：

   | 字段 | 必填 | 说明 |
   |---|---|---|
   | **DeepSeek API Key** | ✅ | 在 [platform.deepseek.com](https://platform.deepseek.com) → API Keys 创建；安装前会用它在 `GET {baseURL}/models` 上做真实校验 |
   | **接口地址 Base URL** | | 默认 `https://api.deepseek.com`；用 OpenAI 兼容网关/中转时改成自己的地址（如 `https://api.deepseek.com/v1`） |
   | **推理强度 Reasoning Effort** | | `off / low / high / max`，默认不改动（保持 dsh-tui 的 max） |
   | **默认模型 Model** | | 默认 `deepseek-v4-flash`；可下拉选 `deepseek-v4-pro`、`deepseek-v4-flash-vision-exp`，也可直接输入任意模型名（需在该接口返回的模型列表中，否则 TUI 会忽略并回落默认；是否勾选「流畅模式」不影响模型生效） |
   | **TUI 版本** | | 默认**稳定版 0.9.3**；可切「尝鲜版 latest」（当前上游 beta 0.10.0-beta.1，含新特性） |
   | **流畅模式** | | 默认勾选：写入性能优化覆盖层（状态行刷新 500ms→1500ms、轻量动画帧），减少卡顿 |
   | **创建桌面快捷方式** | | 默认勾选，一键启动 TUI |
   | **安装完成后自动启动** | | 默认勾选 |

3. 点 **一键安装**，等待日志走完。中途失败会在日志 + 弹窗中给出具体原因。

### 1.3 脚本实际执行了什么

```text
1. 检查/安装 Node.js（>=22.19）
2. npm install -g @deepseek-ai/dsh @deepseek-harness-tui/dsh-tui@<版本>   （官方 CLI + TUI；版本默认稳定版 0.9.3，可选 latest 尝鲜）
3. 检查/安装 pnpm（>=10）
4. dsh plugin --profile dsh-tui add @deepseek-harness-tui/dsh-tui@<版本>
   （创建 dsh-tui profile；版本与步骤 2 一致；自动处理 pnpm 11 的 ERR_PNPM_IGNORED_BUILDS）
5. 用你填写的 Key 校验 DeepSeek API 连通性
6. 写入凭证 ~/.dsh/.credentials.yaml  →  DEEPSEEK_API_KEY: sk-xxx
7. 按需写入 ~/.dsh/settings.yaml 的 llm-deepseek 段（baseURL / reasoningEffort）
8. 写入 ~/.dsh/profiles/dsh-tui/cordis.patch.yml 覆盖层：默认模型 / 推理强度（独立于流畅模式勾选）+ 流畅模式性能项
9. 复制启动器到 ~/.dsh/launchers/，创建桌面快捷方式，启动 TUI
```

> 凭证解析优先级（与官方一致）：进程环境变量 `DEEPSEEK_API_KEY` > `~/.dsh/.credentials.yaml` > 项目 `.env`。安装器写入的是中间那层，改完**立即生效**，无需重启。

### 1.4 启动 / 修改配置 / 卸载

| 操作 | 方式 |
|---|---|
| 启动 TUI | 桌面快捷方式「DeepSeek Harness TUI」，或终端运行 `dsh-tui` |
| 恢复上次会话 | `dsh-tui --resume`（读 `~/.dsh-tui/resume.txt`） |
| 修改 API Key / BaseURL / 默认模型 / 推理强度 | 双击 **`configure.bat`**（只写配置，不重装），保存后下次启动 TUI 生效 |
| 升级 | 重新双击 `install.bat`（默认装稳定版 0.9.3，不会擅自升到 beta；想尝鲜在窗口选「尝鲜版 latest」），或 TUI 内 `/update` |
| 卸载 | `uninstall.ps1`（详见 README） |

### 1.5 命令行模式 / 离线安装

```powershell
# 无窗口安装（自动化/CI）
powershell -ExecutionPolicy Bypass -File install.ps1 -Headless `
  -ApiKey "sk-xxx" -BaseUrl "https://api.deepseek.com" -ReasoningEffort high -Model deepseek-v4-pro -TuiVersion 0.9.3
```

把 `node-v22.x.y-win-x64.zip` 或 `.msi` 放进仓库 `tools/` 目录即可离线安装 Node（安装器自动检测）；npm 包仍需联网。

### 1.6 常见问题：双击 install.bat 没反应 / 窗口一闪而过

新版 `install.bat` / `configure.bat` 已加固：**双击后必定弹出一个终端窗口**（纯 ASCII 内容 + CRLF 换行，任何 Windows 下都不会解析失败），安装进度会实时显示在终端里（GUI 窗口的日志同时镜像到终端），结束后 `pause` 停住等你按键，绝不再"闪退"。

如果在新电脑上仍然"点了没反应"，按顺序排查：

1. **看扩展名**：资源管理器默认隐藏扩展名，`install.bat` 可能实际叫 `install.bat.txt`（双击会打开记事本或毫无反应）。在文件夹选项里勾选"显示文件扩展名"确认，必要时改名为 `install.bat`。
2. **解除"来自 Internet"标记**：从 GitHub 下载的 zip 解压后，`install.ps1` 可能被 Windows 标记为不安全而拒绝运行。右键 `install.ps1` → 属性 → 勾选"解除锁定"（安装器新版会自动执行 `Unblock-File`，此步一般可跳过）。
3. **杀毒软件/Defender 拦截**：360、火绒等可能静默拦截 `.bat` 或 `powershell.exe`。临时关闭再试，或把仓库文件夹加入信任区。
4. **`.bat` 文件关联损坏**：右键 `install.bat` → 打开方式 → 选择"Windows 命令处理程序"（`cmd.exe`）。
5. **窗口一闪而过**（旧版本文件）：说明 bat 是 LF 换行/UTF-8 编码导致解析失败，或脚本已成功退出但没 `pause`。**重新下载本仓库最新版**即可（旧版已修复）；临时办法：在该文件夹开一个 cmd，手动运行 `install.bat` 看报错。

> 提示：终端窗口会一直显示，安装期间**不要关闭它**；日志在终端和 GUI 窗口里都有。

### 2.2 常用指令详解

**`/btw <问题>` —— 侧问（不打断主任务）**
- 复用当前会话上下文（system prompt + 历史）做一次**无工具、单轮**的模型调用，答案显示在浮层面板里；
- **不进会话历史**：不写入 session log、不占主上下文和 token 计数；
- **不打断主回合**：模型正在流式输出时也能触发；
- 面板内 `↑/↓` 滚动、`Space`/`Enter`/`Esc` 关闭、`c` 复制答案；再次触发 `/btw` 会中止上一个侧问。
- 典型用法：主任务跑着的时候顺手问一句「这个报错什么意思？」「`str_replace_editor` 的用法？」

**`/resume` —— 会话浏览器（全屏）**
- 默认列出当前工作目录下的对话，按最近活动排序；`Enter` 恢复、`Tab` 预览、`Ctrl+P` 固定；
- 直接输入可实时搜索（标题/目录/分支/模型）；`Ctrl+A` 切换仅本项目/全部项目，`Ctrl+B` 只看当前分支；
- 子 agent 运行默认折叠（`Ctrl+S` 展开），`Ctrl+X` 清理空会话。

**`/model` 与 `/effort`**
- `/model` 通过 fork 会话切换模型（DSH 没有原位换模型 API），旧会话保留在 `/resume` 里；
- `/effort` 打开推理强度滑杆实时调整，或 `/effort max` 直接设置。

**`/settings` —— 设置编辑器**
- 按命名空间读取/编辑；`↑/↓` 移动、`Enter` 展开/切换、`s` 保存、`d` 放弃、`Esc` 退出；
- dsh-tui 命名空间的字段（`lang`、`statusBar.*`、快捷键等）实时生效，写入 `~/.dsh/settings.yaml`。

**`/compact` / `/export`**
- `/compact` 压缩会话历史（token 占用高时用）；
- `/export` 导出当前会话。

**`/balance` / `/cost`**
- `/balance` 查看 DeepSeek 官方账户余额（摘要行 + hover 明细，点击刷新）；
- `/cost` 查看当前会话成本。

**`/update`**
- 后台会检查 npm 新版本并提示；`/update` 更新 `@deepseek-harness-tui/dsh-tui` 后自动重启并恢复当前会话（仅 `dsh --profile <名>` 启动时可用；当前回合运行中需等它完成）。

**`/trace`（`Ctrl+T`）**
- 整屏轨迹场景：时间线/热点视图，`[`/`]` 跳失败点、`{`/`}` 跳轮次、`/` 查询（`tool:`、`kind:`、`err:`、`>10s` 等）、`m` 切换投影模式、`q`/`Esc` 退出。

### 2.3 消息投递语义（模型工作时）

| 按键 | 行为 |
|---|---|
| `Enter` | **steer**：送入正在运行的回合，在下一步边界被 Agent 领取 |
| `Tab` | **follow-up**：排队等当前回合结束再处理 |
| `Ctrl+Enter` | **interrupt**：打断当前回合并立即投递 |

`Alt/Option+Up` 取回最后一条未处理消息；模型工作时按 `Esc` 中断并重投 pending 消息。

### 2.4 快捷键速查（完整版见官方文档）

**全局**：`Tab` 补全 `/` 命令与 `@` 文件 · `Shift+Tab` 循环会话模式（默认→计划→完全访问）· `Ctrl+O` 展开思考/工具详情 · `Ctrl+R` 历史搜索 · `Ctrl+G` 外部编辑器编辑输入 · `Ctrl+Shift+E` 全屏草稿编辑器 · `Ctrl+T` 轨迹 · `Ctrl+P` loaded-context 面板 · `Ctrl+L` 重绘终端 · `?` 帮助 · 空输入双击 `Esc` 时间回溯 · `Ctrl+C` 中断（再按强制退出）· `Shift+Enter` 多行输入。

**输入编辑**：`Ctrl+A/E` 行首/行尾 · `Ctrl+U/K` 删光标前/后 · `Ctrl+W` 删前一个词 · `Ctrl+←/→` 按词移动 · 有选区时打字替换、`Backspace` 删选区。

**vim 模式（`/vim`）**：`Esc` 切 NORMAL · `h/j/k/l` 移动 · `0/^/$` 行首尾 · `w/b` 词跳 · `x/X` 删字符 · `dd/d$/d0/dw` 删除 · `u` 撤销（100 步）· `i/I/a/A/o/O` 进入插入。注意：vim 开启时 Esc 归 vim 管，时间回溯请退出 vim 后用双击 Esc 或 `/rewind`。

**fullscreen 鼠标**（`fullscreen: true` 时）：滚轮滚动/菜单 · 拖拽选词自动复制 · 双击选词 · 单击工具卡/thinking 展开收起 · 单击子代理卡看详情 · 输入框内拖拽建选区、Shift+click 扩展、双击选词、有选区时 `Ctrl+C` 复制。`DSH_TUI_DISABLE_MOUSE=1` 可关闭。

### 2.5 `@` 文件引用

消息里输入 `@` 打开文件补全：继续输入过滤、`Tab`/`Enter` 选择；支持模糊匹配（`@ment` 命中 `src/utils/mentions.ts`）；输入路径形态（`@src/`、`@./`、`@D:\` 等）时只补全该目录。发送时文本文件内容/目录列表自动附加，图片（PNG/JPEG/WebP/GIF）作为真正的图片块发送；`Ctrl+V` 粘贴文件管理器复制的文件会插入路径、图片自动转 `@` 引用。

### 2.6 环境变量

| 变量 | 用途 |
|---|---|
| `DEEPSEEK_API_KEY` | DeepSeek 凭证（安装器已写入 `~/.dsh/.credentials.yaml`，也可用环境变量） |
| `DEEPSEEK_BASE_URL` | 覆盖 DeepSeek 兼容 API 端点 |
| `DSH_TUI_PERSONA` | 覆盖 Agent persona |
| `DSH_TUI_PRESET` | 覆盖新会话默认 Agent preset |
| `DSH_TUI_THEME` | 锁定主题（auto/light/dark/dark-ansi 或自定义） |
| `DSH_TUI_LANG` | 锁定界面语言（zh/en），优先于 `/settings` |
| `DSH_TUI_DISABLE_MOUSE` | 非空即关闭 fullscreen 鼠标 |
| `DSH_TUI_WORKSPACE_TARGET` | 启动工作区目标（本地路径 / file:// URI） |
| `DSH_TUI_RESUME_SESSION` | 指定要恢复的会话 ID（`--resume` 启动器注入） |
| `VISUAL` / `EDITOR` | `Ctrl+G` 外部编辑器 |
| `DSH_TELEMETRY_DISABLED` | 任意非空值关闭 Harness 遥测 |
| `NPM_CONFIG_REGISTRY` | 覆盖 npm 镜像（影响 `/update` 检测） |

## 三、常见问题

- **启动后立刻退回 shell（几乎无报错）**：pnpm 版本过低（需 ≥10），执行 `npm install -g pnpm@latest` 后重跑安装器。
- **提示 `dsh-tui requires an interactive terminal`**：TUI 必须在真实终端里运行，不要重定向/管道输出。
- **模型启动失败/提示没有凭证**：检查 `~/.dsh/.credentials.yaml` 或环境变量 `DEEPSEEK_API_KEY`；自定义端点同时检查 `DEEPSEEK_BASE_URL`。
- **工作状态行重复**：profile 里重复添加了 `dsh-working-activity`，移除多余的 bundle 配置。
- **TUI 显示错位**：先跑 `/doctor` 查看终端类型与模式。
- **Esc 想回退却退不出**：vim 模式开着时 Esc 归 vim 管；退出 vim 后双击 Esc，或 `/rewind`。
